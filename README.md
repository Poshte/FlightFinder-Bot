# FlightFinder

An automation script that I wrote back in April 2025. I wanted to travel to the city of Shiraz in Iran and needed to find a cheap flight. Instead of checking the website manually every day, I inspected it and found their API. I built this bot to ping the API, parse the JSON, and send me an SMS via an external provider when the price dropped below my target.
During the project I noticed the website checks the User-Agents in each request. I bypassed the risk of getting banned by randomizing User-Agents in each call.
Sorry FlyToday! Shiraz was too beautiful to miss :)

Created this repository in October 2027 to share it with the world.
